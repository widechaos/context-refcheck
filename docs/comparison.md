# Related tools and scope overlap

Reviewed 2026-11-14 using public author documentation and the source files linked below. No competitor was installed or executed; this is a source/feature comparison, not a comparative benchmark or a security audit.

| Tool | Existing overlap | Smallest intended distinction here |
| --- | --- | --- |
| [michal-franc/context-doctor](https://github.com/michal-franc/context-doctor) | Already checks CLAUDE/AGENTS and missing referenced documentation. Its [rules](https://github.com/michal-franc/context-doctor/blob/master/RULES.md) include CD031 broken references, CD032 age, CD052 build/test command presence. | Missing Markdown paths overlap directly. Its reviewed [reference extraction](https://github.com/michal-franc/context-doctor/blob/master/rules/engine.go) recognizes documentation patterns ending `.md`, and [resolver](https://github.com/michal-franc/context-doctor/blob/master/rules/refs.go) follows referenced docs recursively and uses Git/time. Those routines do not resolve `python3 file.py` or npm script keys. Refcheck adds these two static entries, explicitly selects files, and uses no Git/process invocation. |
| [DheerG/context-doctor](https://github.com/DheerG/context-doctor) | Read-only context diagnosis, inventory and duplicate artifact names. Its [inventory source](https://github.com/DheerG/context-doctor/blob/main/plugins/context-doctor/skills/diagnose-agent-context/scripts/context-inventory.mjs) lists context artifacts; its [skill](https://github.com/DheerG/context-doctor/blob/main/plugins/context-doctor/skills/diagnose-agent-context/SKILL.md) guides behavior-based diagnosis. | The reviewed inventory does not parse Markdown command references into Python-file/npm-key checks. Refcheck is a deterministic reference report without running a diagnostic agent. |
| [KushalP1/context-doctor](https://github.com/KushalP1/context-doctor) | Token/cost and integration tooling. Its [doctor source](https://github.com/KushalP1/context-doctor/blob/main/src/doctor.ts) already detects missing paths in configured MCP/hook entries. | Static entry existence is therefore not novel in general. Refcheck reads selected Markdown instruction references, rather than diagnosing integration settings or reading session history. The reviewed doctor/rules/scan modules did not provide the same two Markdown entry checks; this is not a claim about every module. |
| [lychee](https://github.com/lycheeverse/lychee) | Broad local/link checking, including offline mode. | Prefer it for broad links. Refcheck additionally checks two command entry grammars, with much narrower Markdown support. |
| [agent-handoff](https://github.com/AgathonLi/agent-handoff), [context-handoff-bundle](https://github.com/ucsandman/context-handoff-bundle) | Handoff lifecycle, stale references and evidence drift, including hashes in the latter. | Evidence drift is existing functionality. Refcheck's optional declaration binds a whole-file hash to existing instruction text; it does not generate a handoff or infer semantic freshness. |

The useful candidate is a small no-configuration path/entry check for selected instruction files, with explicit skipped/unsupported coverage and strict no-follow access. It is not a new category or proven market gap. Synthetic examples establish behavior, not external demand, adoption or superiority.

The earlier name Context Doctor collides with these projects. Context Refcheck / `context-refcheck` is the provisional candidate. An exact-name public GitHub repository search returned zero results, and PyPI/npm name lookups returned HTTP 404 on 2026-11-14. Search/index gaps and later registrations remain possible; this is not a trademark clearance, reservation or publication approval.
